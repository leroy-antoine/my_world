This program creates a 3D map using isometric projection.

To build this project, clone the repository using git clone, then run make to compile the project.

Next, run ./my_world or ./my_world -h to see how the project works.

Finally, read the menu to understand how my_world works and how to navigate between the different menus.

You have three buttons:

- Plus: When this button is activated, clicking on an element will make it grow.

- Minus: When this button is activated, clicking on an element will make it shrink.

- Reload: Reloads the map to its last saved state.
